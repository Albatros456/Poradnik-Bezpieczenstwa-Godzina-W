# Lokalne kafelki mapy Kielc

Ten folder zostaje jako miejsce na docelowe lokalne kafelki mapy OpenStreetMap dla Kielc.

Działający przykład kafelków offline znajduje się teraz w:

```text
assets/maps/offline/
```

Docelowa struktura plików:

```text
assets/maps/kielce/{z}/{x}/{y}.png
```

Nie należy hurtowo pobierać kafelków z publicznych serwerów OpenStreetMap. Kafelki offline powinny zostać przygotowane zgodnie z zasadami licencji i polityką wybranego źródła danych.
