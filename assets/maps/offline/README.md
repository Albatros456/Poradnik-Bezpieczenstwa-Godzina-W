# Działające kafelki offline

Ten folder zawiera mały zestaw przykładowych kafelków PNG używany przez ekran `app/mapa/index.tsx`.

Struktura kafelków:

```text
assets/maps/offline/{z}/{x}/{y}.png
```

Obecne kafelki są demonstracyjne i służą do sprawdzenia działania trybu offline bez pobierania danych z internetu.

Żeby użyć prawdziwej mapy OpenStreetMap, należy przygotować własny legalny zestaw kafelków i podmienić pliki w tej samej strukturze. Nie należy hurtowo pobierać kafelków z publicznych serwerów OpenStreetMap.
